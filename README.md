# chatserver-moduo-mysql-nginx-redis
集群聊天服务器和客户端代码，服务器基于muduo库实现，使用mysql进行数据存储，nginx负载均衡，redis使服务器订阅消息和发布订阅

./autobuild.sh自动编译构建

安装nginx/redis/mysql
redis和mysql服务安装后自动开启
nginx编译时加--with-stream参数激活tcp负载均衡模块
